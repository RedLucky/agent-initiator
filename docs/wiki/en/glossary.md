# Glossary

## In short
Words used in this project, explained in plain language. If a page uses a term that is not here, add it.

| Term | Meaning in plain words |
|------|------------------------|
| AI coding assistant / agent | A program such as Claude Code, Codex, Cursor or Copilot that writes and changes code for a person. |
| AGENTS.md | The first file an AI assistant reads in a repository: project overview, commands, rules, constraints and links. |
| CLAUDE.md | Claude Code's instruction file. agent-initiator writes one that just says "read AGENTS.md". |
| Rule | A Markdown file in `.agents/rules/` describing how code must be written (for example naming or security). |
| Skill | A step-by-step guide in `.agents/skills/<name>/SKILL.md` that an assistant follows for a task, such as `commit` or `update-wiki`. |
| Agent Skills format | The open standard for skills (agentskills.io): a folder with a `SKILL.md` that has a `name` and a `description`. |
| Preset | A ready-made bundle of rules, skills, commands and constraints for one stack, for example `nextjs` or `fastapi`. |
| Stack | The set of technologies a project uses: language, framework, package manager, monorepo tool. |
| Monorepo | One repository that holds several apps or packages, managed by a tool such as Turborepo, Nx or moon. |
| Scaffolding | Creating a new project's starting files with a framework's official tool (for example `create-next-app`). |
| Package manager | The tool that installs a project's dependencies: npm, pnpm, yarn, bun for JavaScript; uv, poetry, pip for Python. |
| rtk | Rust Token Killer: runs shell commands and shortens their output so AI assistants use fewer tokens. Every command is prefixed with `rtk`. |
| graphify | Builds a searchable map (knowledge graph) of the code so assistants can find things quickly. |
| CI (continuous integration) | A service that runs the project's checks on every push or pull request, on a clean machine. The `ci-quality-gates` rule says what it must run. |
| Lockfile | The file that records the exact version of every dependency (`pnpm-lock.yaml`, `uv.lock`, `go.sum`, …), so every machine installs the same thing. |
| Git hook | A small script git runs at a fixed moment, for example just before a commit is saved. Hooks live in `.git/hooks/` and are not shared through the repository. |
| Quality gate | An automatic check that stops a change when it breaks an agreed rule, such as the commit message format. |
| caveman | A mode that makes AI assistants answer briefly. |
| ponytail | A mode that makes AI assistants write the smallest solution that works. |
| UI UX Pro Max | A design skill for user-interface work, added for frontend projects. |
| Definition of Done (DoD) | The checklist a change must pass before it is finished: self-review, tests with coverage, build, dependency audit, wiki. |
| Coverage | The share of code lines that tests actually run. The Definition of Done asks for at least 80% on changed code. |
| ADR | Architecture Decision Record: a short page explaining an important technical decision and why it was made. |
| Mermaid | A text format for diagrams that GitHub renders as pictures and AI assistants can read as text. |
| Dogfooding | Using our own tool on our own repository; this repository's `AGENTS.md` was generated by agent-initiator. |
